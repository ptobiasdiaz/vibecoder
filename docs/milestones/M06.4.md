# M06.4 — Proyectos desde Git local

Estado: implementado y validado offline.

Incluye inspección local de solo lectura, validación remota independiente,
selección explícita de rama, detección de datos no publicados, workspaces desde
el SHA remoto, registro recuperable y autorizaciones GitHub por proyecto.

El checkout del usuario nunca es fuente de archivos. Un proyecto se hace
visible únicamente cuando repositorio, workspace y usuario inicial quedan
confirmados. No incluye plugins, workers, agentes, bootstrap, Issues, PRs,
scheduler ni operaciones live.
