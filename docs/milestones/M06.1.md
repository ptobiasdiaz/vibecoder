# M06.1 — Provider-neutral foundations

M06.1 establishes the incompatible 0.0.1 domain, segmented plugin contracts,
deterministic worker selection, derived operational state, exact resource
resolution, and SQLite schema version 1.

It intentionally does not implement the daemon, CLI, GitHub login, project
registration, plugin installation, Codex integration, supervisor integration,
Debian package, or live validation.

The historical services are transitional source only and are not claimed to be
executable with schema 1.
