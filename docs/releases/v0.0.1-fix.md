# Fix de recuperación para vibecoder 0.0.1

M06.13 corrige el candidato 0.0.1 sin cambiar su versión:

- intentos inmutables para planes y tareas;
- recuperación de cuota confirmada con backoff persistente;
- comandos `plan retry`, `task retry` y `attempt list`;
- tareas independientes basadas en el HEAD remoto verificado;
- herencia Git de tareas dependientes preservada;
- `UNKNOWN` continúa requiriendo reconciliación.

```bash
sudo apt install --reinstall ./vibecoder_0.0.1_amd64.deb
```

La reinstalación conserva identidad GitHub, secretos, proyectos, workers,
sesiones, planes, aprobaciones y el ledger.


Cuando una tarea reúne varias ramas predecesoras que no pueden integrarse sin
conflicto, queda `BLOCKED`. Vibecoder no inventa una fusión ni convierte ese
fallo confirmado en `UNKNOWN`.
