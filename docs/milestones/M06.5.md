# M06.5 — Plugins, workers and execution isolation

Status: implemented and validated offline.

M06.5 adds declarative trusted-plugin discovery, persistent worker lifecycle,
verified capabilities, deterministic selection, an isolated runtime protocol,
opaque sessions and conservative executions. The complete fake plugin runs in
a separate process and simulates availability, authentication, capabilities,
success, failure, UNKNOWN, quota, timeout, crash, cancellation and observation.

Production launch is designed around distinct pre-provisioned Unix identities
and hardened transient systemd units. Offline tests validate generated policy,
minimal environment, closed file descriptors and protocol behavior. They do not
validate real UID switching or kernel-enforced cross-user denial; that remains
an explicit M06.9 VM requirement.

Codex remains unavailable and reports M06.6. No agents, GitHub operations or
live inference are started.
