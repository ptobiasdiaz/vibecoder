# M06.11 — autonomía de Codex

M06.11 añade las políticas persistentes `autonomous` y `manual`. La primera
permite trabajo ordinario dentro del sandbox Codex sin decisiones por acción;
la segunda conserva íntegro el broker de aprobaciones. El plan exacto sigue
requiriendo aprobación humana y vibecoder nunca realiza el merge.

La implementación usa el contrato verificado de Codex App Server 0.167.0 y
mantiene el aislamiento systemd por UID. Las instalaciones previas migran sus
workers a `manual`; únicamente las altas nuevas del plugin Codex adoptan
`autonomous` por defecto. El cambio se realiza por el socket administrativo y
queda auditado.
