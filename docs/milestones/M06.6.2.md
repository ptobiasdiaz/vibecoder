# M06.6.2 — Codex App Server runtime approvals

Status: implemented offline and validated live on Debian Sid, 2026-11-10.

M06.6.2 adds a neutral approval entity and state machine, SQLite persistence,
a peer-authenticated private worker broker, administrative protocol operations,
and the `vibecoder approval` CLI. Decisions are one-action, attributed to the
kernel-authenticated local actor, audited, idempotent, and deny by default.

Codex 0.167.0 live validation verified a real
`item/commandExecution/requestApproval`, explicit denial, explicit approval,
human-decision expiry, and daemon restart. The approved command created only
the expected file inside the assigned workspace; denial, expiry and restart
created no file. Restart preserved the execution and approval as `UNKNOWN`.

Two integration defects were corrected:

- the standalone Codex binary was missing the official matching
  `codex-code-mode-host`, so tool execution failed closed before approvals;
- a late runtime result could decrement concurrency after daemon recovery.
  Late results now preserve the recovered `UNKNOWN` outcome.

The official helper archive was downloaded only on the authorized VM from the
OpenAI Codex 0.167.0 release and its published SHA-256 was verified before
installation. No GitHub operation was performed.

Offline result: 114 M06 tests passed. Live result details are in
`docs/integration/codex-approvals-live.md`.
