## Defectos corregidos

1. UUIDs no deterministas impedían preaprovisionar el usuario del worker.
2. El launcher directo/sudo no era una frontera productiva; se sustituyó por un
   servicio root de política fija con socket privado.
3. Autenticaciones largas bloqueaban el launcher; ahora atiende en paralelo.
4. Se corrigieron permisos y entorno de storage, temporal y workspace.
5. Se adoptó Codex 0.167.0 con descarga verificada y extracción tar segura.
6. Device Code quedaba en progreso/SQLite; ahora se elimina y solo persiste el
   resultado no sensible.
7. `InaccessiblePaths` impedía arrancar sin socket; se usan rutas opcionales de
   systemd que siguen bloqueándose cuando existen.
8. El framing SOCK_STREAM ahora lee exactamente header y cuerpo.
9. Las unidades transitorias tienen tiempo máximo y matan todo el cgroup.
