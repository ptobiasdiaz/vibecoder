# M06.2 — Daemon and unified CLI

M06.2 implements `vibecoderd`, protocol v1, kernel-derived local authorisation,
derived status/doctor and persistent idempotent pause/resume. With no GitHub or
workers, the healthy daemon reports `STANDBY/OFFLINE`.

The development sandbox prohibits AF_UNIX bind/send. The transport is therefore
tested with byte-exact socket doubles; lifecycle, permissions, persistence and
signal handling are tested without root or systemd. Real socket integration is
reserved for isolated Debian validation in M06.9.
