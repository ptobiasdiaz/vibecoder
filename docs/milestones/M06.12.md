# M06.12 — tutorial y publicación local de vibecoder 0.0.1

M06.12 consolida la línea M06 como release local. El tutorial autosuficiente
está en `doc/tutorial.md`, README funciona como entrada breve y
`doc/release-notes-v0.0.1.md` registra el contrato publicado.

Se contrastaron 40 invocaciones con el parser real y se ejecutó una
comprobación no destructiva contra el paquete instalado en Debian sid:
servicios activos, daemon `READY/ONLINE`, GitHub `ONLINE`, Codex `READY` en
`autonomous`, proyecto y scheduler consultables y cero barreras activas.

Las guías vigentes de instalación, CLI y backup dejaron de enseñar comandos de
la línea 0.4.0. Los documentos históricos M00–M05 no se reescribieron.

El paquete final fue construido dos veces con resultado idéntico:

```text

SHA-256:      b8ddc76b2202ecb42159cff0e69ad58209d2fd291fe59a1d8749f9aed45d4d57
```

La suite offline completa contiene 136 pruebas. La publicación remota y la
GitHub Release quedan explícitamente fuera de este hito.
