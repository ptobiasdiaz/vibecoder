# Validación live conjunta M04.3 + M04.4

## Escenario

Partir de una tarea especialista independiente materializada por M04.2. M04.3 prepara,
ejecuta, valida, publica y abre el PR. Un desarrollador añade comentario/review. M04.4
lo consulta, conversa, registra una corrección `IN_SCOPE`, ejecuta Codex, valida,
publica otro commit en la misma rama y responde. El desarrollador revisa y fusiona;
M04.4 verifica el merge y desbloquea dependencias.

## Separación de efectos

- Solo lectura/local: elegibilidad, start, poll, validate, commit, reconcile.
- Consumo Codex: ejecución inicial, conversación y corrección.
- Escritura GitHub: push inicial, PR, respuestas y push de corrección.
- Intervención humana: review, clasificación/autorización de alcance y merge.

Los workspaces, ramas, PR, comentarios y registros SQLite permanecen tras la prueba.
No se elimina ni cierra nada automáticamente. Los comandos exactos se proporcionan en
la entrega del hito y las variables se describen en los dos tests live.
